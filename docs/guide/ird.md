# 新西兰IRD申请指南

IRD number 是新西兰税务局发放的个人税号。留学生如果准备在奥克兰兼职、申请 KiwiSaver 或处理银行利息税务，通常都需要先申请自己的 IRD number。

## 什么时候申请

建议在找到第一份兼职工作前申请。申请通常需要准备护照、签证信息、新西兰银行账户以及税务居民相关资料。刚抵达奥克兰时，可以先完成银行开户，再用稳定的邮寄地址提交申请。

## 奥克兰新生申请步骤

1. 先准备护照、学生签证和新西兰银行账户资料。
2. 登录 Inland Revenue 官方网站的个人 IRD number 申请页面。
3. 按照护照上的英文姓名填写，不要自行添加中文拼音之外的昵称。
4. 填写奥克兰的现住地址和可接收邮件的联系方式。
5. 提交后保存申请确认信息，等待 IRD 通过邮件或其他方式通知结果。

<TipBox type="info">
如果住在合租房，建议提前确认信件收件人姓名和房屋地址格式。地址写错可能导致补资料或收不到信件。
</TipBox>

## 拿到IRD number之后

把税号交给雇主，用于填写入职税务表格；同时保存好确认邮件或信件。换工作时一般不需要重新申请 IRD number，但要根据实际收入选择正确的税码。
